# 供应链目标库存测算

一个零依赖的静态网页小工具：填入产品的月需求、采购提前期、提前期波动、预测准确率、服务水平、下单周期、MOQ 等参数，一键算出该产品当前的目标库存水平，并展示四段构成与完整换算过程。

电脑和手机浏览器都能直接打开，不需要安装、不需要登录，所有数据只保存在使用者自己的浏览器里。

## 计算口径

```
日均需求   = 月需求 ÷ 月计天数
MAPE       = 1 − 预测准确率
σ需求      = MAPE × 日均需求
Z          = 标准正态分布反函数（服务水平）
提前期需求 = 日均需求 × 采购提前期
安全库存   = Z × √(采购提前期 × σ需求² + 日均需求² × 提前期波动²)
周转库存   = 0.5 × max(日均需求 × 下单周期, MOQ)
冻结库存   = 日均需求 × 冻结天数
目标库存   = 安全库存 + 周转库存 + 提前期需求 + 冻结库存
库存天数   = 数量 ÷ 日均需求
```

- 目标库存向上取整为整数件，同时展示原始小数。
- σ需求 主口径为 `MAPE × 日均需求`，页面另外给出 `1.25 × MAPE` 的参考口径。
- 建议下单量：现有库存 ≥ 目标库存时为 0，否则为 `max(MOQ, ceil(目标库存 − 现有库存))`。

## 更新流程

1. 修改 `index.html` / `styles.css` / `app.js`。
2. 在本目录执行 `.\deploy.ps1 "这次改了什么"`。
3. GitHub Pages 约 1–2 分钟、Cloudflare Pages 约 30 秒后自动更新。
